# Gameplay balance and the todo overhaul

`res://config/gameplay.json` is the balance source. It is loaded once; stop and relaunch the game after editing it (mission restart alone retains cached configuration). The web export explicitly includes `config/*.json`. Invalid JSON, missing sections, negative/non-finite values and invalid critical ranges stop the loading screen with a retry message. Preserve existing roster IDs and required fields. Times are seconds, distances are world metres, rates are per second. Replays require the same configuration.

| Section | Controls |
| --- | --- |
| structures / units / predators / turrets / production | Costs, HP, speed, training/build time, factories, weapons, production roster |
| simulation | Fixed tick (0.1 default), HQ heal radius/rate (7m/3 HP per second), harvesting interval, repair yield, infantry weapons |
| power | Generator/core/repeater radii, outputs, gas cost per served power-second |
| economy / vehicles / resources | Starting reserves and storage; cargo and drilling; hand/extractor yield and mining reach |
| lighting | Emergency, infantry, vehicle/headlight and spotlight radii/intensities |
| world | Map radius/elevation, ridge count/length, field reserves, base grace; sampled layout distances scale from reference radius 84 |
| mission / predators_ai | Extraction radius/time; probe/grace/reinforcement timings and creature cap |
| maintenance / exploration / patrol / scouting / tactics | Maintenance searches, leashes, patrol shape and scout investigation ranges |

Geometry constants (hex shape, neighbor offsets, numerical tolerances), algorithm budgets and source/roster identifiers remain code invariants. Do not change configuration in the middle of a simulation. Static aliases expose the loaded values to existing core callers; the core still has no rendering or wall-clock dependencies.

## Behavior

- Selected units show combined cargo used / total capacity, including when empty. Loaded units also show their materials and methane amounts; both resources share that capacity.
- Player-built ramps and platforms are temporarily unavailable in both the build catalog and engine build commands. Legacy terrain helpers and fixture structures remain for elevation/navigation checks. Walls render as full hex-tile sprites with no connector arms; their placement, health, cost and navigation rules are unchanged.
- Unit spacing anticipates nearby contact and suggests gentle sidesteps before overlap. Idle infantry can make room without replacing their orders or queued work; active work and stopped vehicles are protected from these requests. Corrections respect terrain and the next route segment, and moving units retain their speed limit. Direct move orders reserve separate nearby arrival spots when other movers already claim the destination. Units on different elevations do not repel each other. Route following remains authoritative, with overlap recovery for spawn crowds and no hard unit blockers. Movement stays on fixed simulation substeps.
- Exploration rallies at the clicked starting point, then repeatedly visits the nearest reachable, unclaimed unrevealed tile by horizontal distance. Equal distances prefer tiles nearer the map center, then stable axial cell order. Scouts finish their current trip even if light reveals the destination along the way. Blocked/disconnected tiles are skipped instead of triggering stationary lookout scans; navigation changes make newly accessible tiles eligible again. Cached navigation routes remain private: each caller receives an independent packed array so clearing a finished route cannot strand another scout. Existing crew seating, escorts and direct-order interruption rules still apply.
- Construction clicks pass through units; blueprints remain walkable until completion safely clears their occupants. Engineers build, repair, deliver and collect cargo only from the same or an adjacent footprint tile at the same elevation. Harvesting uses the same one-tile limit, including extractor perimeter tiles.
- Direct mining orders, foot expeditions and convoys retain their assigned resource field across depleted patches and delivery trips. Covered patches stay in simulation data but are hidden and unpickable in the world and minimap. Select or mine the extractor to access its remaining materials and methane; an offline extractor waits for power instead of allowing hand mining underneath it. Destroying it reveals the remaining patches.
- Electrical structures show exactly three power values: signed generation/consumption, current grid capacity, and current grid demand. Disconnected structures show dashes for the two grid values. Units and nonelectrical structures show no grid status. Selecting an electrical structure reveals network links and source coverage; only source/relay placements display outgoing coverage. Build previews explain connection and supply problems. Relays extend range without generating power; generators require methane; HQ supplies 4 emergency power without fuel.
- Structure placement accepts a center with illumination of at least 0.055 or one hex adjacent to such a point, sampled at the site's elevation. This adds one buildable ring along the light edge without extending visibility, discovery, deterrence, or light sources. Terrain, footprint, resource, and clearance requirements still apply.
- Vehicles still require pilots, but do not drain/recharge batteries. Battery fields and the old recharge replay command are inert compatibility data. Charging buttons, hotkeys, status text and bars are gone; zero legacy battery values cannot stop lights, driving, scouting or drills.
- HQ heals living friendly units within its radius, including occupants whose carrier is nearby. Healing requires a living, completed HQ; it caps at each unit's configured maximum HP and never revives casualties.
- Extractors reserve the same seven-hex footprint as HQ. At least one occupied cell must contain a surveyed, nonempty deposit; other occupancy/height/clearance rules still apply. An engineer at any accessible perimeter tile can operate it. Each resource unit is taken from the patch with the greatest remaining fraction of its original reserve, using stable patch order for ties. This balances depletion and preserves mixed-resource ratios, partial cargo capacity and the existing delivery mechanics. Offline extractors retain mining assignments and wait for power. An exhausted clicked patch can continue servicing other covered deposits.
- Repeater links use the sum of both source radii (13.9m to a default generator; 20.8m to another repeater). Consumers connect through any occupied tile. Preview status and live connectivity use the same rules; disabling sources still disconnects their branches.
- `illumination.gd` caches deterministic per-source hex flood fills by geometry/source revision. Ground light sees near blocking faces but cannot propagate through cliffs, closed walls/gates, or onto higher surfaces. Ramp transitions can rise; elevated sources can illuminate equal/lower surfaces. Discovery, enemy visibility and deterrence share this result. The renderer draws the aggregated field in one instanced mask, retaining smoke/terrain coverage and avoiding per-frame per-tile draw calls. Geometry edits invalidate the caches.
- Minimap right-clicks issue contextual orders without moving the camera; left-click/drag still pans. Armed targeting modes support minimap clicks and Shift. Visible contacts and surveyed resource markers snap to their world targets.
- Patrol: an initial unmodified left/right click places a point and exits. Shift left/right clicks queue points and retain targeting. After queueing, unmodified left click finishes without adding a stray point; unmodified right click places a final point and exits. Escape cancels input while retaining the selection.

Validate with the full test runner. `todo-upgrades` covers the core behavior and `command-input` covers world/minimap patrol handling. Existing deterministic replay, logistics, construction, power and lighting suites remain active.
